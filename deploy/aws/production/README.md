# Iki's production deployment on AWS

Every module in [`../modules`](../modules) put together, with the chart's production values
beside it. Copy this directory and `../modules` into your own repository and change what you
need: it's a starting point, not a module to call.

The runbook, from an empty account to Iki serving, is
[Deploy on AWS](https://ikisci.org/guides/deploy-on-aws/), and recovering is
[Restore a deployment from a backup](https://ikisci.org/guides/restore-from-a-backup/).
