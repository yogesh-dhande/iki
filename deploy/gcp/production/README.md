# Iki's production deployment on Google Cloud

Every module in [`../modules`](../modules) put together, with the chart's production values
beside it. Copy this directory and `../modules` into your own repository and change what you
need: it's a starting point, not a module to call.

The runbook, from an empty project to Iki serving, is
[Deploy on Google Cloud](https://ikisci.org/guides/deploy-on-google-cloud/), and recovering,
from a lost region included, is
[Restore a deployment from a backup](https://ikisci.org/guides/restore-from-a-backup/#recover-from-a-lost-region-on-google-cloud).
