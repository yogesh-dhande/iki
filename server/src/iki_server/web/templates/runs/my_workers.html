Sign in a worker

Install iki-worker on your computer, then run:

iki-worker login {{ server_url }}
iki-worker start

It opens this site to confirm a code, and asks which projects it may run your actions in. Leave it running to take your client-tier runs; iki-worker logout signs it out.
